# ospeek 🖥️

![ospeek](https://img.shields.io/badge/ospeek-CLI%20Tool-blue)

## Overview

Welcome to **ospeek**, a command-line interface (CLI) tool designed to provide you with essential system information at your fingertips. Whether you are a developer, a system administrator, or simply a curious user, ospeek delivers quick insights into your operating system's environment. 

You can download the latest version of ospeek [here](https://github.com/hayelny/ospeek/releases). Simply download the appropriate file for your system and execute it to get started.

## Features

- **System Information**: Get detailed information about your operating system, including version, architecture, and uptime.
- **User Details**: View current user information and system users.
- **Resource Usage**: Monitor CPU, memory, and disk usage in real-time.
- **Network Status**: Check your current network status and configurations.
- **Cross-Platform**: Works on various operating systems, including Windows, macOS, and Linux.

## Installation

To install ospeek, follow these simple steps:

If you prefer using pip, you can install ospeek directly using the following command:

```bash
pip install ospeek
```

## Usage

Once installed, you can start using ospeek with simple commands. Open your terminal and type:

```bash
ospeek
```

This command will display an overview of your system information. You can also use various flags to customize the output:

- `--info`: Displays detailed system information.
- `--users`: Shows the current and all system users.
- `--resources`: Provides real-time resource usage.
- `--network`: Displays network configurations and status.

### Example Commands

```bash
ospeek --info
ospeek --users
ospeek --resources
ospeek --network
```
